# Salary Came… Gone! 💸

A tiny SaaS-style salary expense calculator.

## Run locally
Open `index.html` in a browser.

## Deploy
This is a static website, so it can be deployed on a free static hosting service such as GitHub Pages.

## Features
- Monthly salary input
- Expense categories
- Automatic total and balance
- Funny financial messages
- Mobile responsive
- No backend or database required
